# 📦 API de Pedidos

API desenvolvida para cadastro e gerenciamento de pedidos.

## 🚀 Endpoints

### 🔹 GET `/pedidos`
Lista todos os pedidos.

### 🔹 GET `/pedidos/{id}`

### 🔹 POST `/pedidos`

### 🔹 PUT `/pedidos/{id}`
